# My PrepBench notes

Your interview-prep notes from [PrepBench](https://prepbench.testkalyan007.workers.dev), saved in your own GitHub repository.

- PrepBench never stores your notes. The app writes them straight from your browser to this repo, using a GitHub App that you installed on **this repository only**.
- One Markdown file per item, grouped by section: `dsa/two-sum.md`, `js/debounce.md`, `hook/use-debounced-value.md`, and so on.
- Edit them here, in any editor, or in PrepBench. Every save is a commit, so you have full history.
- Keep the repo private if you like; PrepBench works either way.
- To disconnect: GitHub → Settings → Applications → Installed GitHub Apps → PrepBench Notes → Uninstall. Your notes stay here.
